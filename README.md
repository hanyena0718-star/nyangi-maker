# 냥이 메이커

공부하면 고양이가 자라는 공부 앱입니다. 과제와 뽀모도로로 골드를 벌어 고양이를 돌보고, 청년기 2주가 끝나면 직업 엔딩이 나옵니다.

## 폴더 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 앱 전체 |
| `manifest.webmanifest` | 앱 이름, 아이콘, 색 등 설치 정보 |
| `sw.js` | 인터넷이 없어도 열리게 하는 오프라인 기능 |
| `icons/` | 앱 아이콘 |

## GitHub Pages에 올리기 (처음 한 번)

1. github.com에 로그인하고 오른쪽 위 **+** → **New repository**를 누릅니다.
2. Repository name에 `nyangi-maker`를 적고, **Public**을 고른 뒤 **Create repository**를 누릅니다.
   - GitHub Pages 무료 플랜은 공개 저장소에서만 됩니다. 저장소가 공개여도 고양이 기록은 각자 휴대폰에만 저장되고 GitHub에는 올라가지 않습니다.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 압축을 푼 `nyangi-maker` 폴더 **안의 파일과 icons 폴더**를 통째로 끌어다 놓습니다. (`index.html`이 저장소 맨 위에 있어야 합니다.)
5. 아래 **Commit changes**를 누릅니다.
6. 저장소의 **Settings** → 왼쪽 **Pages**로 갑니다.
7. **Source**는 `Deploy from a branch`, **Branch**는 `main` / `/ (root)`로 고르고 **Save**를 누릅니다.
8. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/nyangi-maker/` 주소가 뜹니다.

## 휴대폰에 설치하기

**안드로이드 (Chrome)**
1. 위 주소를 Chrome으로 엽니다.
2. ⋮ 메뉴 → **앱 설치** (또는 **홈 화면에 추가**)를 누릅니다.
3. 앱 목록에 냥이 메이커가 생깁니다. 한 번 연 뒤로는 인터넷이 없어도 열립니다.

**아이폰 (Safari)**
1. 위 주소를 Safari로 엽니다.
2. 공유 버튼 → **홈 화면에 추가**를 누릅니다.

## Claude 링크에서 키우던 고양이 옮기기

기록은 앱을 연 곳마다 따로 저장됩니다. 새 주소로 옮기려면:
1. 기존 Claude 링크의 냥이 메이커에서 더보기 → **저장 파일 받기** (안 되면 백업 코드 복사)
2. 새로 설치한 앱의 더보기 → **저장 파일 불러오기** (또는 백업 코드 붙여넣기)

## 앱을 고쳤을 때

1. 저장소에서 바뀐 파일을 다시 업로드해 덮어씁니다.
2. `sw.js` 맨 위 `VERSION = 'nyangi-v1'`의 숫자를 하나 올립니다 (`nyangi-v2`). 그래야 휴대폰에 저장된 예전 버전이 새 버전으로 바뀝니다.
3. 휴대폰에서 앱을 껐다가 다시 열면 반영됩니다.

## 주의

- 고양이 기록은 휴대폰 브라우저 저장 공간에 있습니다. 브라우저 데이터를 지우거나 앱을 삭제하면 사라지니 저장 파일을 가끔 받아두세요. 앱이 7일마다 알려줍니다.
